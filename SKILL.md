
# SKILL: Diseño de CV-CREATOR-APP inspirado en Tiendas TUTI

## Objetivo
Mejorar la interfaz de la aplicación móvil para crear
currículums, utilizando una identidad visual comercial,
sencilla, consistente y fácil de utilizar.

## Referencia visual
Tomar como referencia la imagen corporativa de Tiendas TUTI.
Verificar sus colores y logotipo en fuentes oficiales antes
de utilizarlos. No inventar un logotipo oficial.

## Paleta de colores propuesta
- Color principal: #D71920
- Fondo general: #F5F5F5
- Tarjetas: #FFFFFF
- Texto principal: #252525
- Texto secundario: #666666
- Éxito: #16803C
- Error: #C62828

Estos colores son una propuesta de trabajo y deben
contrastarse con la identidad corporativa oficial.

## Componentes
- Utilizar tarjetas blancas con bordes redondeados.
- Mantener botones grandes y fáciles de pulsar.
- Usar títulos claros y subtítulos descriptivos.
- Mostrar mensajes de error debajo de los campos.
- Destacar la acción principal con el color corporativo.
- Mantener márgenes y espacios consistentes.

## Formularios
- Mostrar etiquetas encima de los campos.
- Indicar los campos obligatorios.
- Validar los datos mientras se escriben.
- Mostrar errores con mensajes claros.
- Utilizar selectores de fecha para fechas laborales.
- Permitir seleccionar una fotografía del usuario.

## Accesibilidad
- Usar textos legibles.
- Mantener buen contraste.
- No comunicar errores únicamente mediante colores.
- Añadir etiquetas accesibles a botones e imágenes.

## Experiencia de usuario
- Mantener una navegación sencilla.
- Organizar la información en secciones.
- Confirmar cuando los datos se guardan.
- Mostrar una vista previa clara del currículum.
- Mantener el mismo estilo en todas las pantallas.

## Regla de implementación
Reutilizar los componentes existentes en components/.
Evitar repetir estilos y lógica de formularios.
Mantener compatibilidad con Expo y React Native.
